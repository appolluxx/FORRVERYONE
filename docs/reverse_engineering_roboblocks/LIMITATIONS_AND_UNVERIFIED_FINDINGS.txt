1. EXTRACTION SCOPE & OMITTED FILES
--------------------------------------------------------------------------------
A. Intentionally Omitted Dependencies (node_modules):
   - Scope: The original `app.asar` archive contains ~10 MB of JavaScript node_modules,
     and `app.asar.unpacked/node_modules/` contains ~45 MB of native C++ Node addons.
   - Status: These third-party dependency folders were deliberately excluded during the
     ASAR extraction script (`extract_asar.py`) to prevent repo bloat and focus 100% on
     the first-party application source code, firmware, and simulator physics.
   - Consequence: Running `npx electron D:\Workspace\robot\assets\extracted_ide`
     fails immediately with `Cannot find module '@electron/remote/main'`.
   - Resolution: To achieve standalone execution, symlink or copy `node_modules` from
     `C:\Users\john\AppData\Local\Programs\roboBlocks IDE\resources\app.asar.unpacked\node_modules`.

B. Omitted Large Proprietary 3D Part Meshes (microBlock-IDE/products/):
   - Scope: The `products/` subdirectory in `app.asar` totals 791.02 MB of proprietary
     `.ptmesh` files and CAD part assemblies (e.g. `dbm27_w33_chassis.ptmesh`).
   - Status: Omitted from initial source extraction. The standard GLB 3D robot model
     (`models/PT-BOT_Atom_VX.glb`, 6.38 MB) was retained and successfully extracted.

C. Omitted WebAssembly Binaries (microBlock-IDE/robot-sim/vendor/):
   - Scope: `occt-import-js.wasm` (12.3 MB) and `pyodide.asm.wasm` (8.8 MB) were skipped.
   - Status: These are open-source upstream pre-compiled WebAssembly binaries; their
     JavaScript bindings (`occt-import-js.js`, `pyodide.asm.js`) are documented.
