2. Responsibilities:
   - Configures I2C, SPI, and ADC hardware buses on the ESP32.
   - Initializes PCA9685 PWM expander (frequency 1300 Hz).
   - Starts background switch polling task (SwitchLoopTask) on FreeRTOS thread.
   - Provides unified sensor read methods (knob, buttons, ultrasonic, VL53L0X, ADC).
   - Manages IMU calibration checks and calibration splash screen.
3. Key Hardware Allocations:
   - I2C Bus 0: Pin(22) [SCL], Pin(21) [SDA], freq=200000.
   - SPI Bus 1: Pin(18) [SCK], Pin(23) [MOSI], Pin(19) [MISO], baudrate=1000000 (ADC expander).
   - CS Pin for ADC: Pin(15).
   - Potentiometer Knob: ADC(Pin(32)), 11dB attenuation, 12-bit resolution.
   - Tactile Switches: SW_A (virtualized on knob == 0), SW_B (Pin(0), pull-up).
   - Buzzer: PCA9685 Channel 5 (duty=2000 for beep).
   - IMU axis offsets: angles_offset = [roll_off, pitch_off, yaw_off].
4. Key Functions:
   - beep(duration): Emits audible tone for specified seconds.
   - knob_read(): Returns raw 0..4095 ADC reading.
   - switch_read(pin): Returns boolean pressed state.
   - read_adc(pin, is_differential=False): Reads 10-bit SPI ADC channel 0..7.
   - angle_read(axis): Returns normalized 0..360 degree reading for ROLL (0), PITCH (1), YAW (2).
   - ultrasonic_read(trigger_pin, echo_pin): Measures distance via time_pulse_us().
   - VL53L0X_read(scl_pin, sda_pin): ToF distance in mm minus 50mm offset.
   - check_imu_calibrated(): Verifies NVS imu_bias; prompts auto_calibrate if missing.

   - Controls 4-wheel independent DC drive (M1, M2, M3, M4) via PCA9685 PWM registers.
   - Implements PD-stabilized gyro heading lock (forward_degree, backward_degree).
   - Implements trapezoidal ramp-up and ramp-down timed motion (forward_degree_time).
   - Implements spot turning and front-wheel pivot turning (spin_degree, turn_degree_front).
   - Supports both 2WD and 4WD configurations (WD2, WD4) and mecanum wheel kinematics.
3. Key Constants & Variables:
   - forward = 0, backward = 1, left = 0, right = 1, WD2 = 0, WD4 = 1.
   - ramp_up = 0.1 s, ramp_down = 0.1 s, previous_error = 0.
4. Key Functions (Derived with exact line citations):
   - clamp_speed(speed) [L19-20]: Constrains speed between -100 and +100.
   - set_motor_drive(drive_mode) [L22-24]: Sets WD2 (2WD) or WD4 (4WD) mode.
   - drive_single(motor, speed, invert=False) [L26-72]:
     * Translates speed percentage to 12-bit PCA9685 PWM: pwm_speed = int((abs(speed) / 100) * 4095).
     * M1: Direction = ch 12, PWM = ch 13.
     * M2: Direction = ch 14, PWM = ch 15.
     * M3: Direction = ch 10, PWM = ch 11.
     * M4: Direction = ch 8, PWM = ch 9.
   - drive_all(s1, s2, s3, s4) [L73-81]: Drives all 4 channels simultaneously.
   - move(direction, speed) [L83-96]: High-level forward/backward drive.
   - spin(direction, speed) [L97-110]: Tank turn in place.
   - turn_front(direction, speed) [L111-124]: Front pivot steering.
   - turn_back(direction, speed) [L125-138]: Rear pivot steering.
   - mecanum_move(vx, vy, r) [L139-147]: 3-DOF holonomic drive kinematics.
   - stop() [L148-156]: Halts all 4 motors (sets duty=0 on all channels).
   - forward_degree(degree, base_speed, max_speed, kp, kd) [L162-184]:
     * Continuous PD loop calculating: error = degree - board.angle_read(board.yaw).
     * Wraps error to [-180, +180]: if error > 180: error -= 360; elif error < -180: error += 360.
     * Derivative: derivative = error - previous_error.
     * PD output: pd_value = clamp((error * kp) + (derivative * kd), -max_speed, max_speed).
     * Motor speeds: speed_left = base_speed + pd_value; speed_right = base_speed - pd_value.
   - forward_degree_time(degree, start_speed, max_speed, kp, kd, duration_s) [L208-244]:
     * Trapezoidal speed profile combining ramp-up, constant cruise, ramp-down with active PD heading lock.
   - spin_degree(target_degree, small_angle_threshold, stop_threshold, min_speed, max_speed, kp, kd, stable_time=20) [L282-319]:
     * Precision heading adjustment stopping when within stop_threshold for >= 20 ms.
5. Dependencies: board (for PCA9685 and angle_read), utime.
6. Hardware Integration: PCA9685 I2C driver on bus 0 (SDA=21, SCL=22) running at 1000 Hz.
7. Robotics Relevance: Core autonomous trajectory navigation for competition runs.
8. Reuse Potential: Directly portable to standalone Python scripts and Python/C++ simulator synthesis.
