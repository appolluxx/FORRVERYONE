   - setAngleOffset(): Zeroes IMU orientation via rb_call(15).
   - SimTFT tft: ST7789 display simulation object with Adafruit GFX compatible methods (fillScreen, drawLine, drawRect, print).
   - initialize(): Boot sequence (motorStop, setAngleOffset, lcdClear, draw boot logo, beep).
4. Hardware Assumptions: PCA9685 PWM driver, Bosch BNO055 IMU, ST7789 128x160 SPI display.
5. Robotics Relevance: Core API header for all Arduino C++ competition firmware.
6. Reuse Potential: Directly reusable in PT-BOT Tactical IDE for compiling and simulating Arduino sketches.
