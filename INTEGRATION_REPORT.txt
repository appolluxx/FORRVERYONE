This integration report documents the selective porting and rigorous integration of 
five reverse-engineered capabilities from roboBlocks IDE (app.asar unpacked into

3. FEATURE 1: MOTOR CONTROL AND HEADING LOCK
--------------------------------------------------------------------------------
A. Motor Hardware Architecture & Channel Mapping:
  - Configuration: 4 DC geared motors in 4WD (WD4) skid-steer drive mode.
  - Motor Driver: PCA9685 12-bit I2C PWM controller connected to dual H-bridge drivers.
  - Actuator Channels:
    * Motor 1 (Front Left):  Direction CH12, PWM CH13
    * Motor 2 (Rear Left):   Direction CH14, PWM CH15
    * Motor 3 (Front Right): Direction CH10, PWM CH11
    * Motor 4 (Rear Right):  Direction CH8,  PWM CH9
  - Speed Clamping & Scaling:
    PWM Speed = (|Speed| / 100.0) * 4095, where Speed is clamped to [-100, 100].

B. Heading-Lock PD Control Algorithm:
  To eliminate angular drift caused by wheel slip, chassis vibration, and floor irregularities,
  the simulator runs the exact heading-lock PD controller extracted from `Func_Move.ino`
  and `Func_Spint-Turn.ino`:

  1. Error Wrap Normalization:
     error = target_yaw - current_yaw;
     while (error > 180.0) error -= 360.0;
     while (error < -180.0) error += 360.0;

  2. Low-Pass Filtered Derivative:
     raw_derivative = error - previous_error;
     filtered_derivative = 0.70 * filtered_derivative + 0.30 * raw_derivative;
     previous_error = error;

  3. PD Correction Calculation:
     pd_val = (error * kp) + (filtered_derivative * kd);
     pd_val = clamp(pd_val, -max_limit, max_limit);

  4. Differential Steering Motor Distribution:
     * Forward Motion `FF()`:
       m_left  = clamp(base_speed + pd_val, -100, 100)
       m_right = clamp(base_speed - pd_val, -100, 100)
       drive_all(m_left, m_left, m_right, m_right)
     * In-Place Spin Turn `spinDegree()`:
       m_left  = clamp(-pd_val, -100, 100)
       m_right = clamp(pd_val, -100, 100)
       drive_all(m_left, m_left, m_right, m_right)

  5. Verified Tuning Constants:
     * Forward Tracking: kp = 3.5, kd = 17.0, max_limit = 80
     * Cornering / Spin Turn: kp = 1.35, kd = 0.16, min_speed = 28, max_speed = 100
     * Small Angle Deceleration Zone: 22.0°
     * Settling Stop Threshold: 2.2°

C. S-Curve Acceleration and Dynamic Braking:
  - S-Curve Kinematics: Cosine bell profile smooths start and stop acceleration:
    progress = elapsed_time / ramp_time
    s_factor = 0.5 * (1.0 - cos(progress * π))
    speed = min_speed + s_factor * (max_speed - min_speed)
  - Ramp Parameters: ramp_up = 120 ms, ramp_down = 120 ms.
  - Dynamic Braking: Upon reaching target distance or time, a 15 ms reverse polarity
    pulse is applied to the H-bridges before entering high-impedance coast, damping
    chassis inertia and preventing overshooting.

4. FEATURE 2: LINE SENSOR AND LINE FOLLOWING
--------------------------------------------------------------------------------
A. Physical Geometry & Array Layout:
  - Mounting: Front sensor bar offset +100 mm (0.10 m) longitudinally ahead of the
    wheelbase center.
  - Sensor Count: 8 optical phototransistor channels (ADC0 to ADC7).
  - Lateral Spacing: 12 mm between adjacent sensors (total span = 84 mm).
  - Lateral Positions relative to robot centerline:
    W = [-42 mm, -30 mm, -18 mm, -6 mm, +6 mm, +18 mm, +30 mm, +42 mm]

B. Optical Surface Reflectance Model:
  The simulator evaluates the continuous optical interaction between each phototransistor
  and the underlying competition field features:
  - White Vinyl Field Mat:
    * Optical Reflectance = 0.08
    * Raw ADC Reading ≈ 140 (10-bit scale 0..1023)
    * Calibrated Value ≈ 3% (Noise floor)
  - Black Line (20 mm tape):
    * Optical Reflectance = 0.92
    * Raw ADC Reading ≈ 940
    * Calibrated Value ≈ 98%
  - Bamboo Speed Bumps (Rescue Rods):
    * Optical Reflectance = 0.689 (Crucial reverse-engineered finding!)
    * Raw ADC Reading ≈ 705
    * Calibrated Value ≈ 68%
    * Firmware Distinction: Reflectance 0.689 exceeds the floor threshold (>25%) but
      remains distinct from black tape (>90%), preventing false junction triggers.

C. Centroid Calculation:
  Centroid position across the 8-channel array is computed continuously:
    Centroid (mm) = Σ(W[i] * Calibrated[i]) / Σ(Calibrated[i])
    (Sum evaluated only for sensors where Calibrated[i] > 25%).
  If all sensors read floor noise (< 25%), Centroid returns 0.0 mm (Centered).

D. Telemetry HUD Display:
  The HUD displays 8 live optical vertical bars representing ADC0 through ADC7,
  color-coded by surface intensity:
    * Green (> 60%): Black Line or Bamboo Bump
    * Amber (25% - 60%): Transition zone
    * Dark Slate (< 25%): Vinyl floor background
  The real-time centroid offset (±XX.X mm) and surface index (`Mat 0.08`, `Line 0.92`,
  `Bamboo 0.689`) are updated at 60 FPS.
