3. MATHEMATICAL & PHYSICAL MODELING
--------------------------------------------------------------------------------
[MATH-01] Coordinate System & Orientation Convention
  - 3D Simulator Space:
    X: Transverse / Longitudinal field axis [-1.20 m, +1.20 m] (2.40 m total).
    Y: Vertical elevation [0.00 m = ground, 0.050 m = bridge deck, 0.070 m = chassis Y].
    Z: Lateral field axis [-0.60 m, +0.60 m] (1.20 m total).
  - 2D Planner Space:
    Mapped directly to arena grid: 8 columns × 4 rows = 32 tiles (0.30 m × 0.30 m each).
    X_planner = X_3d, Z_planner = Z_3d.
  - Heading Convention:
    0° = Along positive X axis (East).
    +90° = Along positive Z axis (South).
    180° / -180° = Along negative X axis (West).
    -90° = Along negative Z axis (North).
    All turn calculations utilize normalized shortest-arc angular delta:
      delta = atan2(sin(target - current), cos(target - current)).

[MATH-02] Timed Trajectory & S-Curve Translation
  - Velocity Profile:
    The PT-BOT Atom VX chassis with 4 DC geared motors achieves a linear cruise
    speed of:
      v(speed) = (speed / 100.0) * 0.85 m/s
    For a target segment of Euclidean distance d = sqrt((x2 - x1)^2 + (z2 - z1)^2):
      timer_ms = round((d / v(speed)) * 1000)
    Minimum execution quantum is clamped to 50 ms.

  - Turn Duration Estimation:
    In-place spins use `spinDegree(delta)` with gyro PD feedback:
      turn_duration_ms = round((abs(delta) / 90.0) * 380 ms)


4. AUTO PATH ARCHITECTURE & OBSTACLE AVOIDANCE
--------------------------------------------------------------------------------
The Auto Path system is implemented across two clean architectural layers:
  1. Domain Model (`src/core/domain/route_ir.js`):
     - `Waypoint`: Discrete spatial pose (x, y, z, heading, speed, action, desc).
     - `RouteSegment`: Continuous motion path between waypoints, storing turn
       angle, linear distance, move duration (ms), and collision flags.
     - `RouteIR`: Intermediate Representation providing whole-route metrics
       (totalDistance, totalDurationMs, isValid, validationErrors).
     - Collision Engine: Checks continuous swept-sphere volume along each segment
       against:
       * Arena Boundary Walls (outer limits X in [-1.22, 1.22], Z in [-0.62, 0.62]).
       * Pit Hazard Tiles (Cell #11 in Five-Point Route: X in [-0.45, -0.15], Z in [-0.45, -0.15]).
       * Closed Barriers and Bridge Railings.

  2. Path Planner (`src/core/application/path_planner.js`):
     - Discrete Grid Representation: 10 cm discretization (25 × 13 graph nodes).
     - Cost Function: f(n) = g(n) + h(n), where h(n) is Euclidean distance.
     - Barrier Inflation: 15 cm safety radius around pit hazards and walls.
     - Post-Search Shortcut Simplification: Greedy line-of-sight raycaster
       collapses collinear and redundant grid steps into smooth direct waypoints
       while strictly guaranteeing zero obstacle intersection.

  3. Interactive UI Controls:
     - Integrated into the Tactical Simulator 2D canvas:
       * Interactive Click & Drag: Real-time waypoint repositioning with live
         recalculation of distance, timing, and collision state.
       * Heading Vector Handles: Directional arrows visualize robot orientation.
       * Dynamic Validation Card: Highlights path legality and flags pit hazards.
       * Action Toolbar:
         - [Auto Path (A* Avoidance)]: Generates collision-free route automatically.
         - [Add Point]: Inserts waypoint into route sequence.
         - [Recalc]: Recomputes IR and updates 3D simulator trail.
         - [Default]: Restores official competition track preset.
         - [Clear]: Resets route to start and target waypoints.
